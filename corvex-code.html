+what_it_does
    
/* One editor, everything runs */

  

    
▷run
Run anything
Python, JavaScript, TypeScript, Bash, C, C++, Go, Rust, Ruby, Java, Swift and more, with the interpreters already on your computer. Interactive input, terminal colours, time, memory and exit code.

    
⌥flow
Chain scripts into flows
Drag scripts onto a canvas and connect them: what one prints becomes the next one's input, like a terminal pipe you can see.

    
AIagents
Claude Code, Codex and Gemini
Ask the agent you already use, in read, edit or full mode. It gets the open file, the selection and the last output; its changes appear in the editor right away.

    
◉preview
Live preview
HTML, SVG, Markdown, CSV and images update while you type, before you save.

    
■corvex
Corvex reads every line
A local bridge on 127.0.0.1: Corvex analyses what you write with its code agents and the issues land next to the lines. Code never leaves your computer.

    
↻updates
Always up to date
New versions download by themselves and install when you quit, only after the Ed25519 signature and the fingerprint check out.
