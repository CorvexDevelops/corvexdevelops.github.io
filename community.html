+repositories
    
/* Three projects, free to use */

  

    corvex-bench
      
A website, a project and a network capture with 71 known flaws, each with a clean twin. It scores any tool in SARIF or JSON.

      apache-2.0pythonsarif
    corvex-netkit
      
Network capture readers, known-vulnerability matching and network lists, written from public specifications.

      apache-2.0pcapcve
    ai-security-rules
      
Security rules for AI coding agents: CLAUDE.md, AGENTS.md, Cursor, Copilot and Windsurf. Copy them into your project.

      apache-2.0claudecursor
  






  
{}benchmark
    
/* A yardstick you can use too */

    
Every target has a clean twin. Any finding on the clean twin counts as a false alarm. Run it on your favourite tool and compare.

    
  • 71 of 71 flaws found and zero false alarms, offline and without AI
  • the reference blocks any agent that gets worse
