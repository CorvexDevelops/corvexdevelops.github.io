25Nov 2026
latestnew
The System finds remote access programs
BASTION now finds the programs that let someone control the computer from afar: RustDesk, AnyDesk, TeamViewer, Chrome Remote Desktop, VNC, ScreenConnect and remote management agents, on macOS, Windows and Linux.
  1. They often stay installed with nobody remembering them, or an attacker installs them to stay inside: they're signed programs and the antivirus lets them through. The issue becomes high if the program starts by itself at boot or listens on the network, and it explains how to remove it.
  2. If a program is really needed, you authorise it from the issue card by writing who uses it and why. The authorisation also holds for later scans and is recorded in the activity log.
25Nov 2026
new
Scan coverage and «recheck all»
At the end of a web scan the new coverage tab shows how much of the site was really checked: for every page and API, who tested it, what was left out and why. It's in the PDF report too.
  1. After fixing something, «recheck all» re-runs the proof of every open issue with the same harmless probes as the scan and suggests closing the ones that no longer reproduce. You close them, with one click.
25Nov 2026
new
Web scans: adaptive pace and recorded browsing
Every platform has its own pace: gentle for production sites, fast for test environments. If the site answers «too many requests», Corvex slows down by itself and picks up again when the site calms down.
  1. In the desktop app you record a browsing session: you use the site as usual and the agents also test the pages and APIs they can't find by following links, like those of React or Vue apps. From the browser a .har file is enough.
  2. Only the method and address of each request are kept, never cookies or content, and requests that change data are never repeated.
24Nov 2026
new
For teams and companies: GitLab, Bitbucket, SAML and a single view of computers
Besides GitHub, Corvex imports repositories from GitLab, your company's own included, and from Bitbucket, and proposes fixes as merge requests or pull requests on a separate branch.
  1. On the Team and Enterprise plans a new page shows the state of every company computer, and company sign-in also works with SAML 2.0.
  2. In Account the administrator downloads an encrypted copy of all the data and restores it here or on another computer. At the top right there's a button to send us feedback or open a ticket: only you and the Corvex team see it.
24Nov 2026
Web scans: second factor, SSO and cross-user access
Authenticated scans now get into sites that ask for an authenticator code: add the test account's seed and Corvex works out the code itself.
  1. For sign-ins with Google, Microsoft or Okta, in the desktop app you sign in yourself in a separate window. Corvex keeps only that site's session, encrypted.
  2. With a second test account JACKAL checks the most common flaw in dashboards: a user opening another user's orders, invoices or documents by changing a number in the address.
24Nov 2026
corvexai 3.0: it now finds issues on its own
corvexai 3.0, Corvex's AI model, finds issues in code on its own: 19 out of 29 in the test cases, the previous version none.
  1. It is a base model with two parts trained by the Corvex team, one for ORACLE's code analysis and one for the CORVUS chat. Kept apart, each does its job well without getting in the other's way.
  2. On real code it keeps half of the real issues, up from 37%. It sets itself up the first time Corvex starts, about 2.9 GB, with nothing to configure.
21Nov 2026
Every agent sharper: over 50 new checks
Web agents test CSP quality, sign-in cookies, TLS 1.0 and 1.1, APIs and many more exposed files. Code agents recognise modern keys, follow user input inside the function and read every lockfile.
  1. System agents check scheduled tasks, browser extensions, actively exploited vulnerabilities and attacks such as NTLM and Kerberoasting.
  2. Every false alarm found was fixed one by one. The test bench goes from 92 to 215 issues found, without a single false alarm.
20Nov 2026
Team chat, discussion on issues and integrations
Team chat: a channel, direct messages, groups and shared files. Every issue has its own discussion with mentions, an owner and a due date.
  1. Alerts also reach Slack, Microsoft Teams, Jira Cloud or a signed webhook, and evidence or code never leave.
20Nov 2026
SSO sign-in, reviewer role and activity log
Sign in with Entra ID, Google Workspace, Okta and any OpenID Connect provider, with roles taken from groups.
  1. The reviewer role sees everything and can't change anything. The activity log is tamper-evident and exports to CSV or JSON.
20Nov 2026
Scans behind the sign-in too
Every web platform can have a sign-in profile: cookies, headers or a form Corvex fills at the start. Credentials are encrypted and never show in evidence or reports.
  1. Every web issue comes with the exact request, the curl command and a button to retest it.
20Nov 2026
Every pull request checked before merging
Code agents run on every pull request and block the merge when the change adds an issue above the threshold. Results land as SARIF in GitHub's Code scanning tab.
  1. It works from a team machine with Corvex installed or from your company's Corvex server. The code never leaves your machines.
19Nov 2026
VAULTLEECH
Two new agents and security rules for people building with AI
VAULT checks Supabase and Firebase: open rules, tables without Row Level Security, secret keys in the browser. LEECH finds exposed AI keys and endpoints that can blow up your bill.
  1. ai_rules() writes the security instructions for Claude Code, Codex, Cursor, Copilot and Windsurf, so the AI won't repeat the issues found.
18Nov 2026
CORVUS now has a skills library and hands it to the team
CORVUS keeps a library of over 650 defensive security procedures, with MITRE ATT&CK and NIST references.
  1. On every scan it hands each agent the right skills, and every issue gets its own deep dive.
18Nov 2026

Corvex 1.0: meet corvexai
CORVUS now answers with corvexai, the built-in AI model specialised in cybersecurity.
  1. New Guide and Full log sections, deletable reports, a cleaner overview.
  2. From this version Corvex updates itself.
